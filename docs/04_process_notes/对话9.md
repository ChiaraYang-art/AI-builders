## 3. 当前关键代码结构

### 3.1 硬件主程序

当前最重要的 Arduino 主程序是：

```text
arduino/city_sprout_pahub_main_v4_no_flicker_canvas/
  city_sprout_pahub_main_v4_no_flicker_canvas.ino
```

它负责：

- 通过 PaHUB 读取多个 I2C 设备。
- Port 0：DLight 光照传感器。
- Port 1：OLED 黑白文字屏。
- Port 2：ENV-Pro 环境传感器。
- 使用 AtomS3R 内置 IMU 判断 still / walking。
- 使用 Voice Base 麦克风做声音环境检测。
- 根据光照、运动、声音、环境数据判断小芽状态。
- 通过 HTTP `POST /plant` 把状态发给 Flask 后端。
- 接收后端返回的小芽短句。
- OLED 显示状态和文案。
- S3R 彩屏显示小芽动画。
- 轮询 `/latest` 和 `/audio/latest.mp3`，尝试播放后端生成的 MP3 语音。

该主程序依赖本地私密配置文件：

```text
arduino/city_sprout_pahub_main_v4_no_flicker_canvas/arduino_secrets.h
```

这个文件应包含：

- Wi-Fi 名称。
- Wi-Fi 密码。
- 后端 `/plant` 地址。

注意：`arduino_secrets.h` 已经被 `.gitignore` 忽略，不应上传 GitHub。

---

### 3.2 Flask 后端

当前后端已经不是早期单文件版本，而是分层结构：

```text
backend/
  sprout_server.py
  app.py
  config.py
  api/
  ai/
  utils/
  tests/
```

关键入口：

```text
backend/sprout_server.py
```

它会加载：

```text
backend/app.py
```

关键接口：

```text
POST /plant
GET /latest
GET /audio/latest.mp3
POST /walk/start
POST /walk/photo
POST /walk/audio
POST /walk/diary
GET /walk/media/<walk_id>/<file>
```

后端当前能力：

- 接收硬件上报的 state、lux、motion、sound、temperature、humidity、iaq 等数据。
- 生成 `speech_short` 和 `speech_full`。
- 将最新状态保存到内存中的 `latest_message`。
- App 可以通过 `/latest` 轮询最新状态。
- 支持 Color Walk 上传照片。
- 支持 Sound Walk 上传录音。
- 支持生成散步日记和图鉴解锁信息。
- 支持 TTS 生成 MP3，但依赖有效的百炼 API Key。

### 3.3 Vue App

当前主要 App 目录是：

```text
app_demo/08_vue_figma_strict_demo/
```

它是更接近 Figma 高保真稿的 Vue 版本。

主要能力：

- 首页读取 `/latest`。
- 显示小芽状态、文案、光照、声音、温湿度等数据。
- 根据状态推荐不同散步类型。
- 支持 Light / Sound / Color / Local 等邀请页面。
- 支持 Color Walk 上传照片。
- 支持 Sound Walk 浏览器录音上传。
- 支持完成散步后生成日记。
- 支持 diary、map、atlas 等页面展示。

前端开发服务器默认使用 Vite：

```text
npm run dev
```

App 访问地址通常是：

```text
http://localhost:5173/
```

如果 5173 没启动或被占用，也可以指定端口，例如：

```text
npm run dev -- --host 127.0.0.1 --port 5174
```

终端显示：

这说明 Flask 后端已经启动成功。

随后用户在另一个终端运行：

```powershell

npm install
npm run dev
```

但浏览器打开 localhost 失败。

排查结论：

- `http://127.0.0.1:5000/latest` 返回 200，说明后端正常。
- `http://127.0.0.1:5173/` 当时连接失败，说明 Vue 前端没有真正跑起来。
- 本机当时没有 node 进程，进一步说明前端 dev server 没在运行。

随后尝试手动启动前端：

```powershell
npm run dev -- --host 127.0.0.1 --port 5174
```

最终确认：

```text
http://127.0.0.1:5174/
```

可以返回 200。

给用户的解释：

- `http://127.0.0.1:5000` 是 Flask 后端，不是 App 页面。
- App 页面要打开 Vite 输出的地址，通常是 `http://localhost:5173/` 或指定端口如 `http://127.0.0.1:5174/#/home`。
- 只输入 `localhost` 不带端口，浏览器默认访问 80 端口，通常会打不开。

### 6.3 上传硬件主程序

Arduino IDE 打开：

```text
arduino/city_sprout_pahub_main_v4_no_flicker_canvas/
  city_sprout_pahub_main_v4_no_flicker_canvas.ino
```

确认同目录存在：

```text
arduino_secrets.h
```

如果用本地电脑 Flask，Arduino 里的后端地址不能写 `127.0.0.1`，必须写 Flask 启动时显示的电脑局域网 IP：

```cpp
#define SECRET_SERVER_URL "http://<你的电脑局域网IP>:5000/plant"
```

原因：

- 对电脑自己来说，`127.0.0.1` 是电脑自己。
- 对 AtomS3R 来说，`127.0.0.1` 是 AtomS3R 自己，不是电脑。
- 所以硬件访问电脑后端必须使用局域网 IP。
