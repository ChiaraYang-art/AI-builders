# City Sprout Docs Index

这个目录已经按用途重新整理。陌生人第一次浏览项目时，建议先读 `00_project_overview/`，再根据需要进入验证、交接、迭代或过程材料。

## 目录说明

| 子目录 | 内容 | 适合谁读 |
| --- | --- | --- |
| `00_project_overview/` | 项目书、产品规格、原始 PRD | 所有人；用于快速理解项目 |
| `01_product_strategy/` | 产品评审、后端待办与功能优先级讨论 | 产品、工程、商业化讨论 |
| `02_build_run_handoff/` | 验证清单、接线、设计交接、运行交接 | 需要复现 Demo 或继续开发的人 |
| `03_changelog/` | 关键版本更新记录 | 需要了解版本演进的人 |
| `04_process_notes/` | 对话 1-9、阶段进度总结 | 需要追溯构思过程和决策脉络的人 |
| `05_research_prompting/` | Care-based prompting / CHI 风格研究草稿 | 研究写作与概念扩展 |
| `99_external_learning/` | 外部学习材料和模板 | 参考资料，不属于核心项目交付 |

## 推荐阅读顺序

1. 课程提交/老师快速理解：`00_project_overview/TEACHER_PROJECT_BOOK_CitySprout_2026-06-14.md`
2. 面试/作品集 PRD：`00_project_overview/PRD_CitySprout_软硬件一体版_V2.0_2026-06-14.md`
3. 工程与复盘完整版：`00_project_overview/PROJECT_BOOK_CitySprout_2026-06-10.md`
4. 产品规格：`00_project_overview/PRODUCT_SPEC_CitySprout_2026-06-10.md`
5. 复现与验收：`02_build_run_handoff/VERIFICATION_CitySprout.md`
6. 历史迭代：`03_changelog/` 和 `04_process_notes/`

## 关于对话 1-9

`04_process_notes/对话1.md` 到 `04_process_notes/对话9.md` 并不是严格按真实时间排序的线性记录。项目书已经结合文档日期、方案成熟度和实现状态重新整理了时间线；如果只想了解结论，优先读项目书即可。
